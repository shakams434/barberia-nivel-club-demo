# Checklist de datos personales en Perú

Documento operativo editable. No constituye asesoría jurídica. Debe ser revisado por un profesional antes de usar información real.

## Finalidad y transparencia

- [ ] Identificar al titular del banco de datos.
- [ ] Definir finalidades operativas del programa de fidelidad.
- [ ] Separar la finalidad promocional.
- [ ] Publicar un aviso de privacidad accesible.
- [ ] Informar plazo de conservación, transferencias y encargados.
- [ ] Informar cómo ejercer derechos del titular.

## Consentimiento

- [ ] Usar una casilla independiente para mensajes operativos.
- [ ] Usar una casilla opcional separada para promociones.
- [ ] Guardar texto, versión, fecha, fuente y administrador.
- [ ] Permitir retirar promociones mediante `SALIR`.
- [ ] Excluir inmediatamente a quien retire el permiso.
- [ ] No interpretar silencio o casillas premarcadas como consentimiento.

## Seguridad y operación

- [ ] Limitar accesos a administradores autorizados.
- [ ] Usar contraseñas robustas y recuperación segura.
- [ ] Cifrar números, sesiones y secretos.
- [ ] Mostrar teléfonos parcialmente ocultos.
- [ ] Evitar teléfonos y tokens en logs.
- [ ] Mantener auditoría de cambios críticos.
- [ ] Definir copias de seguridad y restauración.
- [ ] Definir procedimiento de incidentes.
- [ ] Revisar contratos con hosting, correo y Meta.

## Derechos y conservación

- [ ] Designar un canal para solicitudes de acceso, rectificación, cancelación y oposición.
- [ ] Verificar identidad antes de entregar o modificar datos.
- [ ] Definir cuándo desactivar, anonimizar o conservar historial.
- [ ] Documentar las excepciones de conservación.
- [ ] Probar exportación y anonimización.

## Registro

- [ ] Determinar si corresponde inscribir el banco de datos personales ante el RNPD.
- [ ] Preparar inventario de campos, finalidades, accesos, transferencias y medidas de seguridad.
- [ ] Completar la inscripción o actualización antes de la operación comercial cuando corresponda.
- [ ] Conservar evidencia de la revisión legal.
